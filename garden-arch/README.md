# Garden Arch Helper

A phone-friendly web app for the BBSI Mathematics 9 Third Quarter Performance Task,
**The Garden Arch** (quadratic functions, similarity, special right triangles, and variation).

| Part | What the app shows |
|---|---|
| Plan | Deadlines with a countdown, progress per part, scoring rubric, "copy all as text" |
| A | Checks the width (2.0–3.0 m) and height (2.4–3.0 m) limits; solves for a in vertex form (exact fraction), standard form, zeros by extracting square roots and by the quadratic formula, properties table with meanings |
| B | Table of values with solutions, graph drawn to scale, second arch with a different a and how the shape changes |
| C | Height 0.6 m from the center and whether the 1.2 m × 1.8 m cart fits, with the cart drawn under the arch |
| D | Scale factor, corresponding lengths and ratios, and a cardboard template (model coordinates in cm) |
| E | Braces with a 45-45-90 or 30-60-90 triangle, lengths in decimal and exact form, labeled diagram, warning if a brace would cut into the arch |
| F | Direct variation C = kL with the arch length measured by straight pieces; inverse variation T = 24/n table for 1–6 workers; design summary |
| G | 1 Corinthians 3:10 prompts and a draft box |

## Teacher Check

Open **Plan → Open Teacher Check** (or add `#teacher` to the link). It asks for the teacher PIN first; only a SHA-256 hash of the PIN is stored in the code (`TC_HASH`). Type in a student's width, height, second a, scale, brace choice, and price to get the full answer key.

Everything is saved in the phone's browser. Works offline after the first visit.

Link for students (GitHub Pages): `https://compact-criterion.github.io/auto-manae/garden-arch/`
