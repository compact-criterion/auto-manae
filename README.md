# Graph Quest

A phone-friendly graph theory puzzle game. It is a single file (`index.html`) with no dependencies, and it works offline.

- **Bridge Walker**: Euler paths and circuits (odd-degree rule), including "Impossible!" levels
- **Map Painter**: graph coloring and chromatic number (Petersen and Grötzsch graphs)
- **Shortest Route**: Dijkstra shortest path
- **Cable Layout**: minimum spanning tree (Kruskal)

Play: open `index.html` on a phone, or host the folder (e.g. GitHub Pages) and share the link.
