# Graph Quest

A phone-friendly puzzle game for graph theory and modular algebra. It is a single file (`index.html`) with no dependencies, and it works offline.

- **Bridge Walker**: Euler paths and circuits (odd-degree rule), including "Impossible!" levels
- **Map Painter**: graph coloring and chromatic number (Petersen and Grötzsch graphs)
- **Shortest Route**: Dijkstra shortest path
- **Cable Layout**: minimum spanning tree (Kruskal)
- **Clock Algebra**: modular arithmetic in ℤₙ: linear congruences, inverses, square roots, Chinese Remainder Theorem, Fermat's Little Theorem, and shortest walks using +a / ×b moves

Each mode ends with harder "challenge" levels, outlined in orange on the menu (44 levels in total).

Play: open `index.html` on a phone, or host the folder (e.g. GitHub Pages) and share the link.
